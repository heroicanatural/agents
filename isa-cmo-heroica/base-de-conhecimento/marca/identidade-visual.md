# Identidade visual da Heroica (o que a Isa já sabe)

Registro do que foi confirmado pelo Roberto nas conversas. Quando o guia de
marca completo for anexado, ele prevalece.

## Tipografia

- **Fonte oficial: Pilcrow Rounded.** Títulos em bold, corpo em regular.
  Roberto pediu em 04/11/2026: "sempre use a fonte Pilcrow Rounded".
- Limitação conhecida: a API do Canva não troca a família da fonte de um
  texto já existente. Textos criados via API saem na fonte padrão. Para
  garantir a Pilcrow, ou o deck nasce com a fonte no brief do create-design,
  ou o ajuste é feito à mão no editor.
